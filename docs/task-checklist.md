# AI 番茄时钟任务清单（执行版）

## 使用说明
- 执行顺序：按阶段从上到下
- 每项完成后将 `[ ]` 改为 `[x]`
- 每阶段结束后先做一次自测，再进入下一阶段

## 阶段 0：项目初始化
- [ ] 创建基础目录结构（`src/`, `data/`, `tests/`, `docs/`）
- [ ] 创建基础文件（`app.py`, `requirements.txt`, `.env.example`, `README.md`）
- [ ] 在 `requirements.txt` 写入最小依赖（streamlit, python-dotenv, openai 等）
- [ ] 在 `.env.example` 提供环境变量模板（如 `OPENAI_API_KEY=`）
- [ ] 在 `app.py` 渲染一个基础页面标题和占位内容
- [ ] 本地启动验证：应用可正常打开且无报错

验收点：
- [ ] 项目可运行，页面可访问

## 阶段 1：倒计时模块（核心）

### 1.1 状态管理
- [ ] 定义计时状态枚举/常量：`idle`, `running`, `paused`
- [ ] 设计 `session_state` 初始化方法
- [ ] 统一状态字段：`duration_sec`, `remaining_sec`, `timer_status`, `last_tick_ts`

### 1.2 计时引擎
- [ ] 实现开始逻辑（从当前剩余时间启动）
- [ ] 实现暂停逻辑（冻结剩余时间）
- [ ] 实现继续逻辑（从冻结点恢复）
- [ ] 实现重置逻辑（回到 1500 秒）
- [ ] 实现归零处理（触发完成事件）

### 1.3 UI 接入
- [ ] 实现时间显示面板（`mm:ss`）
- [ ] 实现控制按钮区（开始/暂停/继续/重置）
- [ ] 按状态显示可用按钮

### 1.4 自测
- [ ] 连续操作开始-暂停-继续 3 次无异常
- [ ] 重置后稳定回到 25:00
- [ ] 倒计时不会出现负数

验收点：
- [ ] 倒计时闭环可稳定运行
