# 番茄时钟项目需求文档

## 1. 项目概述

### 1.1 项目名称
Pomodoro Clock（番茄时钟）

### 1.2 项目目标
构建一个基于 Python + Streamlit 的极简番茄时钟应用，支持 25 分钟专注计时、暂停/继续、每日统计，以及专注任务清单管理。

### 1.3 技术栈
- Python 3.10+
- Streamlit
- 数据存储：JSON（MVP 阶段）

## 2. 需求范围

### 2.1 必做功能（MVP）
1. 25 分钟倒计时
2. 暂停 / 继续
3. 重置
4. 每日统计（当天完成次数、总专注分钟数）
5. 专注任务清单（创建、完成、删除、与番茄计时关联）

### 2.2 非目标（当前阶段不做）
1. 用户系统与多账号
2. 云端数据库
3. 多语言与国际化
4. 移动端原生 App
5. AI 建议与外部模型调用

## 3. 用户场景与流程

### 3.1 主要用户
- 需要专注学习/工作的个人用户

### 3.2 核心使用流程
1. 用户打开应用，看到当前倒计时（默认 25:00）
2. 用户创建或选择一个专注任务
3. 点击开始，计时进入运行状态
4. 可在运行中点击暂停，再点击继续恢复
5. 完成一个番茄钟后自动记录专注记录，并累计到当前任务
6. 页面展示当天统计数据与任务完成进度

## 4. 功能需求明细

### 4.1 倒计时模块
- 默认时长：1500 秒（25 分钟）
- 状态：`idle`、`running`、`paused`
- 行为要求：
  - 开始：从当前剩余时间开始倒计时
  - 暂停：冻结剩余时间
  - 继续：从暂停点恢复
  - 重置：恢复到 1500 秒并回到 `idle`
  - 归零：自动停止并触发“完成一次番茄”事件

### 4.2 每日统计模块
- 每次番茄完成后写入 `SessionRecord`
- 统计维度（至少）：
  - 当天完成次数
  - 当天总专注分钟数
- 按“自然日”聚合（本地时区）

### 4.3 专注任务清单模块（阶段3）
- 任务基础能力：
  - 新增任务（标题必填）
  - 标记完成 / 恢复未完成
  - 删除任务
- 任务与番茄绑定：
  - 用户可选择“当前专注任务”
  - 番茄完成后，自动为该任务累加：
    - `pomodoro_count +1`
    - `focus_minutes +25`（或按实际计时时长折算）
- 任务看板展示：
  - 今日任务总数
  - 已完成任务数
  - 每个任务的番茄数与累计专注分钟

## 5. 非功能需求

### 5.1 可用性
- 页面元素清晰，操作路径短
- 用户在单页面内完成所有操作

### 5.2 性能
- 常规交互响应应在可感知即时范围内
- 统计与任务操作应在一次交互内完成反馈

### 5.3 稳定性
- 计时器不应出现重复计时、负数计时
- 数据写入失败时应有错误提示且不导致页面崩溃

### 5.4 可维护性
- 采用模块化结构：timer / stats / tasks / ui 分层
- 核心逻辑与 UI 分离，便于测试与迭代

## 6. 数据结构建议

### 6.1 SessionRecord
- `id`: str
- `started_at`: ISO datetime str
- `ended_at`: ISO datetime str
- `duration_sec`: int
- `completed`: bool
- `date`: YYYY-MM-DD

### 6.2 DailyStats
- `date`: YYYY-MM-DD
- `completed_count`: int
- `focus_minutes`: int

### 6.3 TaskRecord
- `id`: str
- `title`: str
- `completed`: bool
- `pomodoro_count`: int
- `focus_minutes`: int
- `created_at`: ISO datetime str
- `updated_at`: ISO datetime str

## 8. 验收标准（MVP）
1. 倒计时准确运行 25:00 -> 00:00
2. 暂停/继续行为正确，无跳秒和重复计时
3. 完成一次番茄后可在当天统计中体现
4. 可创建任务并在列表中展示
5. 完成番茄后，当前任务番茄数和分钟数正确累加

## 9. 风险与应对
1. Streamlit 重跑机制导致状态错乱
   - 应对：统一使用 `st.session_state` 管理状态机字段
2. 任务与计时完成事件重复绑定导致重复累加
   - 应对：在计时归零处保证完成事件只触发一次
3. 本地 JSON 文件读写冲突
   - 应对：MVP 阶段简化为单用户本地使用，后续可迁移 sqlite

## 10. 里程碑建议
1. M1：计时器闭环完成（开始/暂停/继续/重置）
2. M2：每日统计可持久化并正确聚合
3. M3：专注任务清单接入完成并可用
4. M4：基础测试与 UI 打磨完成
